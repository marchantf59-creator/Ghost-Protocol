# 🛡️ Ghost-Protocol: Seguridad Biométrica Descentralizada

### **Descripción**
Sistema de seguridad de **Confianza Cero** que separa la llave de acceso (ESP32) de los datos, usando **IA local**.

### **Especificaciones Técnicas**
* **IA:** Reconocimiento facial con algoritmo **LBPH**.
* **Estabilidad:** Filtro de **Media Móvil** para cambios de luz ambiental.
* **Doble Factor:** Validación por proximidad inalámbrica **BLE**.
* **Cifrado:** Estándar **AES-256** gestionado por hardware.
